# 秒传Pro —— 123 云盘秒传 / 转存 一体化面板

> 长期VIP 专用。把「超千万级分享转存」和「GB 级 JSON 秒传导入」两条最重的活儿，收到一块能盯、能排队、能远程管理的面板上。
>
> 种发布形态（单文件 exe / Docker 双架构镜像）一号同源。

---

## 它解决什么问题

123 云盘的批量搬运有两处最疼的地方：

- **分享转存**动辄成千上万条、跨很多层目录，人工点、脚本跑都容易漏、断、乱。
- **秒传（JSON 清单导入）**单个清文件就是几百 MB 到 GB 级，条目上万，还夹着一堆不想传的大文件。

秒传Pro 把这两件事做成**任务 + 队列**的统一模型：先在本地把计划算清楚（逐层、逐条、带校验），再由队列按你的设置一批批往云上落；全程可暂停、可续跑、可核对到底传没传全。不需要一直开着浏览器，也不需要守在电脑前。

---

## 核心能力

### 千万级分享转存

- 一条分享链接就能建任务，**递归下钻**整棵目录树、逐批转存，超大规模（千万级、含"超百万"被拒后自动降级逐批）不中止。
- **失败台账 + 重试**：记下落没落全的目录，支持本任务内重试，也能自底向上"点名"只补失败那几条路径。
- **逐层校验对账**：每层落盘后回读数量与总容量比对，明确告诉你"这层齐了 / 还欠几条"。
- **频控友好**：撞上云端限流按批次边界收手、等一会儿再重试，不把剩下的额度一次烧光；云端迟迟不回话改成定期再问。
- 任务身份 = 链接 + 勾选内容 + 目标目录，任一不同即视为新任务，互不串账。

### GB 级 JSON 秒传导入

- 直接吃大体积秒传清单（JSON），**台账按目标目录分账**，模拟与真实两条口径各走各的断点，重跑不重复、不漏。
- **JSON 内部目录浏览**：不用先把大清单拆成小文件，面板 / 机器人里直接展开清单的内部目录树看结构。
- **自主选择秒传**：建任务时勾选清单里的某个内部目录，自动切出一份子清单并入队，只秒你要的那部分。
- **自定义大文件过滤**（默认针对 10GB 一档，可改阈值、可开关）：超大文件跳过，不拖累整趟。
- **每日秒传限额排队**（按额度排队，超限自动进入"超限等待中"，到点续跑）：默认量级约 20 万/日，避免顶穿云端日限。

### 分享链接 → 秒传清单（导出）

反向也行：把一条分享链接的内容读成一份秒传 JSON 清单存下来，导完自动封箱、做完整性校验、三层数字（清单 / 台账 / 云端）互相对账。

## 任务与队列

- 所有任务在「任务与队列」这一处统一盯：**自动运行开关 / 暂停 / 继续 / 停止**、排队顺序一目了然。
- **排队 = 排到队尾**（等前面的按序跑完自动轮到它）；要"插到最前只跑这一条"用"立即执行"，两者分得很清楚。
- 跑完的任务显示口径一致：已结算的行不再挂着"可操作"的按钮，避免"状态说完成了、按钮还亮着"。
- 右上角实时显示当前是"空闲 / 真实云端 / 演练"，真实写入与演练一眼可分。

## Telegram 机器人：手机上盯着跑、远程管

把面板接到你自己的 TG 机器人上，出门在外也能建任务、看队列、翻清单：

- **配对即用**：面板生成配对码、手机 `/start <配对码>` 绑定了就能用，令牌一按即废、防重放。
- **常用命令**：`/help`、`/send`、`/files`（列表只看不操作，`/files <编号或任务名>` 才进详情卡带按钮，支持 `tree` 内部目录树 / `rename` 改名 / `del` 删除）、`/queue`（全队列带编号与状态分布）、`/task`、`/dirs`（选目录定落点）、`/check`（校验账号连通性）。
- **收到分享链接自动给二选一**：存到网盘 / 转为秒传清单，点了就**排进队列**（跑不跑仍由面板的"自动运行队列"开关说了算，机器人不替你决定"现在就往云上写"）。
- **收到的 JSON 清单**自动落进面板的"清单目录"，重名自动顺延。
- **卡片式消息 + 快捷命令菜单**，文本树整块呈现、文件名完整不截断、每页 50 条翻页，几万项的大清单也不会把单条消息顶爆。
- **海外 VPS 也连得上 TG**：直连腿只解析 IPv4 并逐条兜底、黏住通的那一条，没有 IPv6 路由的机器不用改 hosts、不用加启动参数就能连上机器人。

## 免浏览器登录（无图形界面的服务器也能用）

在 VPS / 容器这类没有浏览器环境的地方登录 123 账号：

- **账号密码登录**与**扫码登录**两种方式（面板画出二维码，用手机 App 扫一下即可）。
- 登录后凭证落盘、连通性当场验一次；凭证被云端拒了会念出原话（HTTP 状态 / 业务码 / message），不再谎报已登录。
- 登出会叫停在跑的活儿、合上排队开关，不留残留。

## 安全与合规设计

- **长期VIP 专属闸门**：判据直读账号的长期 VIP 标识；读不到账号、或不是长期 VIP，直接挡下真实写入。这道闸门在发布形态里是"承重"的——写入规格在构建期密封、运行期带进程内在场证明。
- **真实 / 演练（模拟）双口径**：默认演练不落云端，验证逻辑不碰真实数据；确认无误再切真实。
- **不搬你的数据**：容器里若清单目录没挂到卷上，程序只做启动自检并明确告警（日志一行 WARN + 设置页黄条），把"换镜像会丢清单"这一面照出来并给出挂卷出路，绝不擅自移动或重置你的工作区。
- **Docker 形态自带访问门**：默认开启用户名+密码登录门，首次运行打印一次性设置码而非令牌；会话到期需重登；改密码会清掉所有会话。

## 平台与发布形态

| 形态 | 说明 |
| --- | --- |
| **单文件 SEA exe** | 把整应用压进一个 `.exe`，`Start-Panel-Sea.cmd` 直接跑，适合不想摊开一堆文件的场景。 |
| **Docker 镜像（amd64 + arm64 双架构）** | 真双架构构建，两种架构各自起一次性容器冒烟验证过；一条 `docker run` / compose 起面板，自带访问门。 |

- 支持 **Windows 桌面**、**Docker 容器**，覆盖 **AMD64 与 ARM64** 两类平台。
- 适配**海外 VPS 部署**：免浏览器登录 + TG 直连 IPv4 回落，服务器上没有图形界面、没有 IPv6 也能跑起来并连上机器人。
- 三种形态同一构建号发布，界面可见名「秒传Pro」、包名统一 `123FastlinkPro`。

> Docker 起容器时记得给清单目录单独挂一卷（或把它指到已经挂上的数据卷里），这样换镜像不会丢历史清单。
