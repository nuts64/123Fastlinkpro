## 第一次运行会被安全软件拦一下，这是预期的

把资源注进 Node 那个 exe 会**破坏它原本的 Authenticode 签名** —— 构建脚本在这一步会明明白白打印
`warning: The signature seems corrupted!`。所以第一次跑，Windows SmartScreen 或杀毒软件很可能弹警告、
甚至直接把这个文件隔离。这是"签名没了"的必然结果，**不代表文件被人动过**。

- 想核对拿到的是不是同一份：`PACKAGE-INFO.txt` 里写着 `exe sha256`，本机用
  `certutil -hashfile FastLinkPanel.exe SHA256` 算一遍对上即可。
- 被隔离了：从隔离区恢复、加白名单；不想跟杀毒软件较劲就**用常规版**（那个包不做注入，签名不动）。
- 别拿它和 `node.exe` 比图标、比文件属性：它就是那台 Node 的同一份拷贝，只改了内部字节。

# 秒传Pro v1.5.5 —— 123 云盘秒传 / 转存 本地面板 · 使用说明

这份文件只讲**这个程序能做什么、怎么用、遇到现象怎么办**。它随发布包一起发出去，
与程序界面左上角那行 `秒传Pro v1.5.5` 是同一个版本号，报问题时对着它说就行。

---

## 一、这个程序做什么

把 123 云盘的 JSON 秒传流程搬到一个本机控制面板里，四件事：

| 能做什么 | 说人话 |
| --- | --- |
| **秒传导入** | 吃一份秒传 JSON 清单，把这些文件"以哈希认领"进你的网盘目录，不需要先下载再上传 |
| **秒传导出** | 反过来：把你网盘里的一个目录（或单个文件、或**别人分享的一条链接**）列成一份同款 JSON 清单 |
| **链接转存** | 把别人分享链接里勾选的内容存进你自己的网盘目录 |
| **任务与队列** | 上面三样都在这里建任务、排队、启停；一次只跑一条 |

配套还有 **凭证**（登录态）、**云端目录**（在网盘里翻路径）、**设置**、**概览**（导入/导出进度并排看）。

它**不是**下载器、不做转码、不管理网盘里的文件；超大清单不会丢数据、不会吃满内存，断了能续跑。

## 二、怎么启动

1. **先把整个 zip 解压**（右键 → 全部解出），不要直接在压缩包里双击。
2. 双击 **`Start-Panel-Sea.cmd`**。这台机器不需要装任何东西：运行环境和程序一起在那一个 `FastLinkPanel.exe` 里。
3. 稍等片刻会弹出一个没有地址栏的应用窗口，就是面板。**屏幕上不会再有那个黑色控制台。**

- **关掉那个面板窗口就等于关掉整个程序**（引擎和队列一起收），进度停在最后一个检查点，下次双击接着跑；想让它继续跑就别关那扇窗口。
- 再双击一次不会起第二个后端：已经有面板在跑时，只会再给你开一个窗口。如果那个进程比这份程序旧（缺功能），或者你指定的端口被它占着，
  **会弹一条本机通知**，里面写着该执行的关闭命令 —— 按它说的结束那个进程，再双击一次就行。结束进程不会丢进度。
- 因为控制台被藏起来了，原本只写给控制台看的那几句要紧话（已有面板在跑、那个进程太旧、窗口没能自动开成）改成**弹一条本机通知**；
  日志照旧落在工作区的 `logs\panel.log`。要看实时输出就带参数启动：`Start-Panel-Sea.cmd --show-console`。
- 弹出的是 Edge 应用窗口（Windows 自带 Edge）。没有 Edge 时用命令行 `Start-Panel-Sea.cmd --no-browser`，
  再自己开浏览器访问工作区日志 `logs\panel.log` 里那一句「无头模式：浏览器打开 …」，它带着完整地址和令牌。
- 窗口一片空白、或界面写着"连接中断，轮询中"：面板进程被关了，重新双击即可，进度不会丢。

**数据不在程序目录里**，在工作区 `%LOCALAPPDATA%\123pan-fastlink-gui`。删掉程序包，账还在；删掉那个工作区，账就没了。

## 三、动手之前要知道的三件事

1. **真实秒传和转存都不可撤销。** 网盘没有"撤销这一批"，同一批重发一次就多一批副本。
   所以第一次请务必**把量收窄**（用目录树切一小段、或把日限额填个小数字），跑完去网盘里核对确实多出了这几个文件，再放开跑。
2. **本程序只面向 123 云盘的长期VIP 账号。** 判定不通过、或者根本没读到账号信息时，
   所有真实写入一律挡住，点下去只会得到一句"长期VIP校验没通过：……"，一条请求都不会发出去。
   这一步不需要你配置任何东西，读的是账号本身。
3. **凭证和账号信息只写在本机工作区，界面上不会出现令牌原文。** 公共电脑用完请至少点一次 **登出**，
   或者直接把工作区文件夹删掉。

## 四、第一次用（建议顺序）

1. **凭证** 页 → 那张「登录 123 云盘」卡上面有一排切换条，**四种方式选一种就行，不用挨个点**
   （登录窗口 / 账号密码登录 / 扫码登录 / 手动导入）。选中的那一种会记住，刷新页面也还在这一格。
   - 默认是 **登录窗口**：点 **打开登录窗口**，在弹出的官方登录页面里像平时一样登录（扫码/短信/密码都行）。
     面板自己把登录态取回来存到本机，不需要你导出粘贴任何 JSON。取回之后它会**自己验一次连通性**，
     "当前凭证"那一行从"尚未验证"变成"已登录：〈账号名〉"。**长期VIP** 那一张卡跟着变绿，才算可以往下走。
   - 这台机器根本开不出浏览器（跑在容器里、无头的机器都算）：切到 **账号密码登录**，
     填手机号或邮箱加密码，点 **登录** 就把登录态取回本机 —— 这一步不开任何窗口，密码只写进本机那份凭证文件，
     界面上不会出现它，日志里也不会有。密码错、要验证码那一些，屏幕上念的是官方那边的原话，照着改就行。
   - 也不想把密码交给这个程序、又开不出浏览器的（容器、无头机器）：切到 **扫码登录**，
     点 **生成二维码**，屏幕上是这张由本程序自己画出来的码，用手机上的 123 云盘 App 扫一下、在手机上点确认就登好了，
     全程不输密码、不开窗口。**这张码是本程序自己画出来的，还没用手机上的 App 真扫过一次** ——
     扫不上的话先切回 **账号密码登录**；一张码大约两分钟后会自动作废，点 **刷新二维码** 换一张。
   - 装过相关插件、或不想把密码交给这个程序的：切到 **手动导入**，
     把**已经登录好的那台机器**工作区里的 `cred.json` 整份打开复制、贴进 **粘贴 JSON**，点 **保存并解密** 就行。
   - 「当前凭证」那一行如果翻成红底 **凭证已被云端拒绝**：**光重新登录没用**（登录窗口记着旧登录态，取回来还是同一份被拒的），
     请点 **登出并重新登录**，它把凭证、账号信息和登录窗口的本机登录状态一起清掉再让你登一次。
2. **任务与队列** 页 → **新建任务**。三种任务都在这里建（类型下拉里选），**任务名自动就是清单文件名 /
   你选中的那个目录名**，也可以自己打字（清空就打回自动）。每个任务一套独立的账，换一批清单不会串档。
   按下 **创建并排队** 就直接进队列排在队尾，不用再点第二下。
   - 表单里两个地址格**只能由紧挨其右的按钮挑进来，不能手打**（手打的代价是"选错清单"这种一跑就收不回来的错）。
   - 「读」的那一格永远是你本机或网盘里被取用的东西，「写」的那一格才是要落地的地方。
3. 建完之后，左上角的下拉菜单和任务表里的 **查看任务** 都能切到它，**秒传导入** / **秒传导出** 页跟着变成这条任务的详情。
   先按 **重新扫描**（导入）或 **确认源**（导出）认一遍——**这两步只读、一条云端请求都不发**，
   清单里的坏记录、超大文件、缺哈希都会在这一趟数出来。
4. **第一次跑真的**请把量收窄：用 **🌳 浏览目录树** 勾一小截 → **另存为小清单** → **用这份小清单建导入任务**，
   跑完去网盘核对，再放开整本。
5. 跑不跑只由**一颗**按钮管：它按当下阶段念 **开始秒传 / 继续秒传 / 重试秒传 / 已完成**（导出那一族换成
   **开始导出 / 继续导出 / 重试导出 / 已封箱**）；**暂停** 与 **停止** 是另外两颗。
6. 顶部 **自动运行** 开关决定"跑完一条要不要自己领下一条"，**它默认关着**，面板重启后一定是关的
   （真实秒传不可撤销，必须人再点一次）。

## 五、各栏目的用法

### 秒传导入（清单 → 网盘）

- **清单文件（读取）**：本机那份 JSON。**建任务那一刻文件头就已经读回来了**——大小、修改时间、自报条数、编码方式
  当场写进「任务详情」，不用先点一次"读取文件头"。清单还没拷过来不挡建任务，界面照实说"还没读到"，文件到位再 **重新扫描**。
- **云端目标目录（写入）**：网盘里的目录，用 **☁ 从云盘选择** 挑。
- 进度卡分两格：**本轮已秒传**（只算这一趟新增）与 **累计已秒传**（这条任务的整本账）；容量单位按网盘那套十进制
  （1 MB = 1,000,000 字节），和你在 123 云盘里看到的对得上。
- **失败与重试**：数还有救的剩几条、按原因分组、可以导出 CSV；按 **重试秒传** 只重发没成的那些，
  已经秒传过的不会再发一遍。
- 每一趟结束都留下一份**本次传输详情**账单（经手、各类计数、容量、耗时、重试救回几条、收摊原因），
  面板重启不会被抹成 0。
- 「当前任务」那张卡是**只读**的：要换清单或换目录，回 **新建任务** 重建一条。

### 秒传导出（网盘 / 分享链接 → 清单）

新建导出任务时会多一格 **导出源**，二选一：

- **☁ 从云盘目录生成**：源可以填相对路径（如 `影视/4K 原盘`）、目录 FileId，或在 **☁ 从云盘选择** 里翻到那一层选用；
  **也可以只挑一个文件**，那份清单就只有它那一条记录。
- **🔗 从分享链接生成**：粘一条分享链接（提取码在链接里就自动解出来，解不出就填那一格），
  再点 **🔗 从分享链接选择内容** 逐层点开、勾要导的项——**勾目录就连它底下全部一起导，勾单个文件就只写它那一条，
  一项都不勾就是整条分享全导**。产出的就是同款秒传 JSON，拿去 **秒传导入** 可以把这棵目录树复刻进你自己的网盘。
  这一族**只读云端、不往你的网盘写一个字节**。

其它：

- **清单保存位置**要么写完整文件名（`D:\gr库.json`），要么只写一个**已存在的目录**；别只写盘符（`D:` 会被当成
  "D 盘的当前目录"而失败）。
- ⚠️ **没封箱的清单缺一个右括号，不能直接导入。** 正常跑完会自动封箱；中途停下的点 **就地封箱** 立刻得到可用清单
  （代价是更深的目录不再列了，且封过箱就不能再接着写）。封过箱的作业两侧都给不出"开始"，这是刻意的。
- **校验完整性** 一个云端请求都不发，随时可点：台账层 / 云端层 / 文件层三层对账，结论只有
  **校验通过** / **校验通过（有提醒）** / **校验不通过**（并逐条点名）。任何一次新的开始都会清掉上一次的结论。
- 状态写着 **未列完 · 有目录被页数上限截断**：不是失败，是清单确实不完整。把页数上限调大，点 **继续导出**，
  被截断的目录会重新排队补列，已写的部分不会重复。
- **导出与秒传互斥**（打的是同一个账号的配额）：任一在跑，另一个会被挡住并告诉你先停谁。
- 清单头部只留一处出处 `shareKey`，**提取码与整条链接都不写进去**（清单是要交出去的，码不是）。
- **分享链接失效时这一趟当场终止**：三处状态格都念 **已终止 · 分享已过期**，那颗按钮**不再递「重试导出」**
  （再按也不会好）——换一条有效的分享链接另建任务。半途失效会把已经写出的那几条留在文件里但不封箱，
  想先用这一批就点 **就地封箱**；"提取码错误"不算失效，那种照旧给重试。

### 链接转存（分享链接 → 你的网盘）

- 建任务、改地址都在 **任务与队列** 那一页；**链接转存** 那一栏只看待选中的这一条（只读的信息与参数、启停、逐批结论）。
- 类型选 **链接转存** → 粘分享链接（各种粘贴形状都认，提取码带在链接里也行）→ **🔗 从分享链接选择内容**
  逐层点开、勾要存的几项（可翻页、跨页累积，顶上"已勾 N 项"是实时数）→ **☁ 从云盘选择** 挑存进哪个目录 →
  **创建并排队**。多选算**一条**任务，名字自动取第一项 +「等」。
- 按下 **立即执行**（或计划卡那颗 **转存进网盘**）会先弹一句确认，按下去就是**真往网盘里写**。
  内容多时面板会按目录结构逐层建同名目录往里存，一批有结论了才发下一批。
- **停止** 收手的位置是批次边界：正在问云端的那一批不掐断，之后的批次一项都不发，那些记 **「没发出去」**（不是"没存成"）。
  **已经存进去的那些不会回退。** 停在第一条之后，排在后面的那条绝不会自己开跑。
- 结论分得很细：**已转存 N 项**（云端每批都回了"跑完"）／**失败**（点名是哪一批没成、后面几批没再发）／
  **「没确认」**（云端到时间也没给结论——它可能已经落盘了，先去目标目录看一眼再决定要不要重发）／
  **只出了计划（没存）**。
- 内容特别多、或一次没存全时，看 **超百万逐层递归** 那张卡：**失败台账** 一行一项（名字、欠在哪一层、云端原话、试了几次），
  把原因解掉之后点 **重试失败的 N 项**——它只补台账里那几条、只发回它们各自那一层，不会重存整棵。
  跑完点 **跑一次校验**，两侧各数一遍（缺 / 多 / 大小不符 / 类型不符 / 同名重复 五档分开，没数完绝不报"一致"）。

### 任务与队列

- 任务表本身就是队列：**导入和导出共用一条队列，严格按顺序一个跑完再跑下一个**。行上的 **立即执行** 插到队首，
  **↑ / ↓** 调顺序，**出队** 只是不再排队（任务登记和台账都不动）。
- 任务状态同时写在侧栏下拉、任务表那一行、业务页顶部横幅三处，读的是同一份判据，不会各说一套。
- **日志全站只有一处**：页面底部常驻的 **运行日志**，切换任务时它跟着换成那条任务的日志。
- **移除** 默认只取消登记、**保留台账**（随时能重新打开这一条再对账）；勾上"连台账一起彻底删除"必须
  **照抄界面上那行任务名**才放行——台账是对账的唯一依据，删了就找不回来。

### 云端目录 / 设置 / 概览

- **云端目录**：点目录名进这一层，点面包屑回上级，能翻页，能选中回填到表单。导出的源允许定到一个文件，导入的目标只认目录。
- **设置**：并发、限速、分块、失败重试、导出参数、转存参数都在这里（部分要勾上"专业模式"才摆出来），
  改完对下一次派单生效；运行中的那一趟按当下设置即时生效。
- **概览**：导入和导出两张进度卡并排，不切栏目也知道现在在忙什么。

### Telegram 机器人（手机上盯着跑）

**设置页**里那一张机器人卡是这一族唯一的入口：它只是把手上的面板接进一个 Telegram 私人聊天，
所有动作仍然落在这台机器上——**不开这个开关，机器人一个字都不会替你建任务**。

**打通只需要一次**：① 在卡里填 bot 令牌（令牌是在 Telegram 的 BotFather 那里领的，只有"保存"这一步会写进本机设置）；
② 点 **生成配对码**（十分钟有效、用一次即失效，明文只在这一次显示，界面上重新打开就看不到了）；
③ 手机上把界面上那句完整的 `/start 六位码` 发给你的机器人；④ 卡上显示已绑定即可。
不想用配对码的也能在右侧直接填自己的聊天号绑定。**换了令牌，旧的配对一律作废**，要重新走一遍。

能用的命令（界面的「可用命令」表、聊天里的快捷菜单与 `/help` 是同一批，不会各说一套）：

| 命令 | 做什么 |
| --- | --- |
| `/status` | 面板与当前任务状态 |
| `/check` | 替你再向网盘验一次账号连通性，并念出对方的原话 |
| `/queue` | 全部任务与各自的编号（含已完成的，按台账追加序排） |
| `/task <编号或任务名>` | 看指定那一条任务的详情 |
| `/log [N]` | 最近 N 行运行日志 |
| `/pause` / `/stop` | 在批次边界停下 / 停止（已经传上去的不回退） |
| `/resume` / `/gate on|off` | 继续这一条 / 开或关自动排队（后两条要设置页授权） |
| `/files` | 看秒传清单文件，可读内部目录树、改名、删除 |
| `/send <编号或名称>` | 把指定那份清单当文件发过来 |
| `/notify on|off` | 事件推送开关（跑完了要不要主动告诉你） |
| `/dirs` | 逐层翻目录，定自动建任务的落点 |
| `/help` | 全部命令 |

**自动建任务**（默认关着）：开启且三项落点都填齐之后——收到秒传清单 JSON 会自动排一条导入任务；
收到分享链接会先发来一张 **保存到网盘 / 转为秒传文件** 的按钮卡，点哪一路就按哪一路建，按钮按一次即失效（防止误重放）。
开关关着时机器人只登记收件、不建任务，收到链接也只回一张"已识别"的卡（念分享号与识别方式，不建任何东西）。
**那三项落点不用手打路径**：设置页每一格后面都带着按钮，网盘那两格点 **☁ 从云盘选择** 进目录页翻到要落的那一层、
本机那一格点 **📁 浏览…** 挑一个文件夹，挑完当场填回那一格，保存前会跟着界面刷新留着；在外面时用 `/dirs` 也一样定得了。
落点没填齐的那一路不会自动建任务，界面上会点名说还缺哪一格。

**收到的清单落在哪里**：和你在设置页指定的**清单目录**同一个位置，不在别处另建一份收件箱。
**同名不会覆盖**——文件已经在那儿了，新收到的这份在扩展名前加 `-2`、`-3` 依次顺延，界面上点名建任务时找得到它。

**`/files` 那张卡**：每行是「编号 · 状态 · 条目 · 大小 · 创建 · 名称」，条数读的是那份清单自己写的，
大小优先用本机量到的字节。按 🌳 只读地翻这份清单**内部的目录树**（一层只列一层，统计含更深的那些，
还会告诉你撞过上限没有）；✏️ 改的是**这份清单文件在本机的名字**（改登记也改文件，不影响任务本身的地址）；
🗑 删除会先弹一张确认卡，选"连文件一起删"要把作业名回填确认。清单还没生成时，卡上会说清是哪一种情况：
还在跑、被截断或失败、还是说已完成但那个位置上现在没有这份文件。

**隐私与边界**（这几条是设计，不是遗漏）：**提取码从不在机器人消息里回显**，卡片只说"认出来了没有"；
令牌与聊天号只存在本机那份设置里，不进日志；机器人只念条数与结论，凭证一个字都不上屏。
还有两件事得说在前头：**机器人要能连上 Telegram 服务器**，这台机器连不通就是收发不了，
可以在卡里填代理（优先用你填的那一条，其次读系统环境变量、再看系统代理设置，最后才直连）；
而**云端那一头的成败永远以面板上的台账为准**——机器人念的是这台机器登记的东西。

## 六、大文件过滤（默认 9.5 GB）

**新建任务**那张卡上有一颗勾选 **跳过大的文件** + 一个数字框（出厂预填 9.5，单位 GB），**只对本条任务生效**。

- 不勾就是老行为，一条都不会漏；勾上之后，超过那道线的记录**只统计、不处理**，
  既不发秒传请求，也不为它建父目录，也不会写进导出的清单。
- 阈值可以改成别的数；填 0 或留空就是回到出厂那道线。**正好等于阈值的文件不算超**（判的是严格大于）。
- 统计与开关无关：过滤开着还是关着，扫描都会如实报出这份清单里有多少个大文件、占多少容量——先看清，再决定要不要过滤。
- **它不是坏数据**：被过滤掉的记录在台账里仍是"未决"，所以想补传，就用同一份清单**另建一条不勾选的任务**。
  开关还开着时点重试，引擎会明确跳过并说明缘故，不会白扫一遍。

## 七、秒传导入日限额与「超限等待中」

**任务与队列** 页顶部那张卡：**默认 200000 条/日**，可改成别的数，**填 0 关掉限额**。它数的是**今天真正写进网盘的秒传导入条数**
（无效记录、失败、被过滤的大文件都不占额度）。

- 撞到上限就停在批次边界，任务状态翻成 **超限等待中**（虚线标签 +「第 N 位」），之后一条请求都不发。
- **等 25 小时自动排队续跑**（不是"过午夜就放行"），等待期间队列不会整条停下，后面的导入依次进入等待、顺序不变。
- 这期间对导入的启动/重试/立即执行都会回绝并把原因念出来（已用多少、上限多少、还剩多久）；
  **秒传导出与链接转存不受这项限额影响**，队列照原顺序往下跑。
- **改限额当场生效**：往上调或填 0 之后立刻重判，那一刻挡的理由没了就马上放行，不用干等 25 小时。
- 面板或机器重启不会把今天清零；但**重启后队列一律不开闸**，需要人点 **继续排队**。

## 八、别家的清单文件读得动吗

读得动。导入吃的是一份 JSON 清单，面板认的是"同义写法一族"而不是只有自家那一种：

- 记录数组可以叫 `files` / `records` / `list` / `data`；
- 自报条数可以写 `totalFilesCount` / `fileCount` / `totalFiles` / `filesCount`
  （`filesWithEtag` 是"其中带哈希的条数"、不是总数，故意不认，听它就会把整份清单读少）；
- 路径可以是 `path` / `fullPath` / `filePath` / `relativePath` / `fileName` / `name`；
- 哈希可以是 `etag` / `md5` / `fileMd5` / `contentMd5`；大小可以是 `size` / `fileSize` / `bytes`，写成字符串的也读成数；
- 平铺头部、多行缩进、什么头部字段都没写的裸数组都算能读。

读不动的情况会**点名说清楚**，不会静默丢掉：base62 哈希、分片哈希、源数据本来就没写哈希，三种各说一句；
JSON 本身残缺时，已完整的那几条照样读得到，剩下那半条当场报"JSON 不完整"并给出位置。

云端列表接口不保证带哈希：导出时缺 MD5 的文件会批量补问一次；两处都问不到的记录会被跳过并在进度里报条数。

## 九、常见问题

| 现象 | 怎么办 |
| --- | --- |
| 启动失败：`FastLinkPanel.exe is missing from this folder` | 多半是没解压就在压缩包里双击；全部解出再试。这个文件是"注过载荷的 Node"，杀毒软件比常规包更容易把它隔离，所以那句"看隔离列表"在这里更当紧 |
| 一直 4 条/秒上不去 | 是云端在压速（风控/限流）。改用**慢速重试**处理剩余顽固记录，别提高并发 |
| `database is locked` | 有两个面板在同抢一个工作区，关掉多余的 |
| 界面提示"监听 0.0.0.0"心里发毛 | 面板默认只听本机，局域网里别人连不上；不确定就当作只有你自己打得到 |
| 「验证连通性」或秒传整批报 HTTP 404 | 接口换过域名，面板默认走新域；手上若有更早写入的凭证，重新点一次 **打开登录窗口** 即可落到新域 |
| 验证失败那句话里的"业务码"是什么意思 | 只看 HTTP 200 分不出来，**成不成看业务码**：`401`/「未登录」/「登录已过期」是凭证不被认（走 **登出并重新登录**），`404` 才是域的问题 |
| 明明登录成功了，长期VIP 那栏还说"没能确认会员身份" | 点一次 **验证连通性** 让它重新读一份账号信息；仍然报这一句，就是这个号确实不是长期VIP |
| 界面写着「已完成」，网盘里却没有这些文件 | 先看「任务详情」与顶部横幅报的是**哪一本账**：真实云端台账会写明目标目录；如果这台机器上用环境变量开着演练，那里会改报演练那本账并写明"网盘里还没有这些文件" |
| **同一份清单换了一个目标目录，结果一条都没传** | 真实云端的账是**按目标目录分本**的：换目录就是换一本空账，任务会退回「待开始」，下一趟从第一条真发到新目录，上一个目录的账一格不动 |
| 任务状态是「**超限等待中**」，点什么都没反应 | 那是日限额撞到了，不是坏了。等（25 小时后自动续跑），或者把上限改大 / 填 0 关掉 |
| 导出的清单导入失败、JSON 解析报错 | 先点 **校验完整性**：多半是没封箱（缺一个右括号）。回导出页点 **就地封箱** |
| 导出报 `EPERM: operation not permitted, mkdir 'D:\'` | 保存位置只写了盘符。写成完整文件名或一个已存在的目录即可，不用重启，也没有跑坏的任务要修 |
| 新建的导出任务一点就报 `网盘里找不到目录：X` | 要么这一条是被演练标记带起来的（那句会补一句"问的是内置虚拟树，不是真实网盘"），要么源写的名字网盘里真没有；在 **云端目录** 里挑一个存在的，或直接填目录 FileId |
| 刚更新的页面点按钮报 404，或者干脆没有那个按钮 | 界面是新的、后端还是旧进程：重新双击一次启动器，它会弹一条本机通知写出该执行的 `taskkill` 命令（凭证页那张卡也写着在跑那个进程的 PID 和端口），照它结束那个进程再双击 |
| 转存点下去**只出计划、网盘里没多东西** | 看计划卡顶上那条横幅说的是哪一档：演练档（一次写请求都不发）／旧版留下的计划（点 **重新出计划**）／勾选是空的或全被同名挡了。**只有"横幅写着已转存 N 项而网盘里看不到"才是问题** |
| 转存跑到一半停在「失败」，可前面几批已经落进网盘了 | 这是刻意的：一批没成就不发后面那批，而**已经存进去的不会回退**。先照那张批次表核对哪几批进了，再决定要不要重来；重来的时候同名过滤会把已落盘的挡在外面，不会堆双份 |
| 日志连着刷「请勿频繁操作，请稍后再试」 | 遇到云端判频时面板在原地等一等再重发同一批，等满几轮仍被拒才会收手，剩下的逐条进失败台账。别并行开第二条 |
| 那一列写着 **「没确认」**，到底存没存 | 云端到时间也没给结论，**既不算成功也不算失败**。去目标目录那一层看一眼：在就别管，确实不在再重发 |
| 想彻底删掉一条任务 | **移除** 默认保留台账（随时能对账）；要连账一起删得照抄界面上那行任务名 |
| 换机器 / 搬家 | 整个工作区文件夹拷走即可（台账在那里，不在程序目录里）；程序包重解压就行 |

## 十、数据与隐私

工作区 `%LOCALAPPDATA%\123pan-fastlink-gui` 里都有什么：

- `panel.json` —— 本机端口与一次性访问令牌；`cred.json` —— 123 云盘登录凭证。**这两个含密钥，别分享、别提交到任何地方。**
- `account.json` —— 账号信息回执（昵称、容量那一类），里面没有登录令牌，但同样是你账号的信息，别分享、别提交到任何地方。
- `registry.json` —— 任务登记表与排队顺序；`tasks/<任务>/` —— 每条任务的台账、断点与逐层结果；
  `exports/` —— 导出的清单与其台账；`extracts/` —— 从目录树切出来的小清单；`logs/` —— 运行日志。
- `edge-login-profile/` —— 登录窗口自己的登录状态；**登出** 会连着凭证一起清掉它。

**真实秒传与转存不可撤销，落进网盘的东西面板不会替你删。** 公共环境用完请点 **登出**，或直接删掉整个工作区。
